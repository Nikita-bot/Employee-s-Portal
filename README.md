# Employee's Portal

Портал для управления задачами сотрудников.

## Описание

Employee's Portal - это веб-приложение, предназначенное для управления задачами сотрудников компании. Платформа позволяет создавать, назначать и отслеживать выполнение задач, а также управлять информацией о сотрудниках и подразделениях.

## Основные функции

- Аутентификация пользователей
- Управление задачами (создание, назначение, выполнение)
- Управление новостями
- Просмотр информации о сотрудниках
- Интеграция с Telegram

## Технологии

### Бэкенд
- Go (Golang)
- Echo framework
- PostgreSQL
- Redis
- JWT для аутентификации

### Фронтенд
- Vue.js
- Vite
- JavaScript

## Установка и запуск

### Требования

- Docker и Docker Compose
- Go 1.19+
- Node.js 16+

### Запуск с помощью Docker

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd Employee-s-Portal
   ```

2. Создайте файл `.env` на основе `.env.example` в директории `backend`:
   ```bash
   cp backend/.env.example backend/.env
   ```
   И настройте переменные окружения согласно вашей конфигурации.

3. Запустите приложение с помощью Docker Compose:
   ```bash
   docker-compose up -d
   ```

### Запуск вручную

#### Бэкенд

1. Перейдите в директорию бэкенда:
   ```bash
   cd backend
   ```

2. Установите зависимости:
   ```bash
   go mod tidy
   ```

3. Запустите приложение:
   ```bash
   go run cmd/main.go
   ```

#### Фронтенд

1. Перейдите в директорию фронтенда:
   ```bash
   cd portal-front
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите приложение:
   ```bash
   npm run dev
   ```

## API документация

API задокументировано с помощью Swagger. После запуска бэкенда документация доступна по адресу:

```
http://localhost:8080/swagger/
```

Также вы можете ознакомиться с файлом спецификации [swagger.yaml](backend/swagger.yaml).

## Структура проекта

```
Employee-s-Portal/
├── backend/                 # Бэкенд приложение (Go)
│   ├── cmd/                 # Точка входа
│   ├── internal/            # Основной код приложения
│   │   ├── entity/          # Сущности
│   │   ├── handlers/        # Обработчики HTTP запросов
│   │   ├── repository/       # Репозитории для работы с БД
│   │   ├── service/         # Бизнес-логика
│   │   └── pkg/            # Вспомогательные пакеты
│   ├── migrations/           # Миграции базы данных
│   ├── swagger.yaml         # Документация API
│   └── .env.example          # Пример файла конфигурации
├── portal-front/            # Фронтенд приложение (Vue.js)
├── export/                  # Сервис экспорта данных
├── nginx.conf               # Конфигурация Nginx
└── docker-compose.yaml      # Конфигурация Docker Compose
```
